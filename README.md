# Multi-Page-Website-CocoaTech

A modern, warm, and responsive four-page website for a fictional technology company called **CocoaTech**, designed with a consistent peach-and-chocolate-brown aesthetic using vanilla HTML5, CSS3, and JavaScript.

## 🎨 Color Palette
- **Main Background:** `#FFF8F0` (Warm Cream)
- **Primary Peach:** `#F4B6A6`
- **Light Peach:** `#FFE3D8`
- **Dark Chocolate Brown:** `#5C3D2E`
- **Medium Brown:** `#7B4B35`
- **Terracotta Accent:** `#C8795A`
- **White:** `#FFFFFF`

## 📁 Pages & Structure
- `index.html` — Home page with hero, values, highlights, and services overview.
- `about.html` — About Us page detailing CocoaTech's story, mission, and goals.
- `services.html` — Services page showcasing Web Development, Website Design, and Technical Support.
- `contact.html` — Contact page with client-side form validation and success alerts.
- `style.css` — Responsive stylesheet with CSS variables, fluid typography, and micro-interactions.
- `script.js` — Client-side form validation and mobile navigation toggle logic.

## 🚀 Getting Started
Open `index.html` directly in any web browser, or serve it locally using:
```bash
npx serve .
# or
python -m http.server 8000
```
